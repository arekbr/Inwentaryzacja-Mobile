# Play Console — gotowe odpowiedzi do skopiowania

Wszystko czego potrzebujesz do wypełnienia Google Play Console przy publikacji aplikacji **Inwentaryzacja Mobile**. Pliki ułożone w kolejności wypełniania w panelu.

| Plik | Sekcja Play Console |
|---|---|
| [`listing-pl.md`](listing-pl.html) | Main store listing (PL) — title, short/full description |
| [`release-notes-v0.1.0.md`](release-notes-v0.1.0.html) | Internal Testing → Release notes |
| [`data-safety.md`](data-safety.html) | App content → Data safety |
| [`content-rating-iarc.md`](content-rating-iarc.html) | App content → Content rating (IARC) |
| [`target-audience.md`](target-audience.html) | App content → Target audience and content |
| [`permissions.md`](permissions.html) | App content → Sensitive permissions (CAMERA) |

## Kluczowe linki przy uploadzie

- **Privacy policy URL:** `https://arekbr.github.io/Inwentaryzacja-Mobile/privacy/`
- **AAB:** `android-app/build-android-release/android-build/build/outputs/bundle/release/android-build-release.aab`
- **High-res icon (512×512):** `play-assets/icon/ic_launcher_512.png`
- **Screenshots (telefon):** `play-assets/screenshots/`

## Track upload

1. Pierwsza publikacja → **Internal testing** (do 100 testerów po e-mailach)
2. Po sprawdzeniu → **Closed testing** (open beta)
3. Stabilne → **Production**

Internal testing nie wymaga pełnego store listing review przez Google — wystarczą minimalne meta + AAB.
